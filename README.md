# Цифровая обработка сигналов

Интерактивное приложение для подготовки к зачёту по цифровой обработке сигналов: теория, генератор практических задач, формулы, пошаговые решения и тренировочные билеты.

Работает в браузере на компьютере и телефоне.

## Открыть приложение

**[Цифровая обработка сигналов — GitHub Pages](https://so1ow4y.github.io/digital-signal-processing/)**

## Возможности

- Теоретические карточки с ответами, объяснениями формул и примерами.
- Режим запоминания и перемешивание вопросов.
- Отметки «Знаю», «Ошибся» и «Повторить».
- Генерация практических задач с разными исходными данными.
- Автоматическая проверка числовых ответов и последовательностей.
- Подсказки и пошаговые решения.
- Графики последовательностей и структурные схемы.
- Поиск по теории и практике.
- Справочник основных формул.
- Настраиваемые тренировочные билеты.
- Локальное сохранение прогресса.
- Адаптивный интерфейс и тёмная тема.

## Темы

В приложении представлены теория и задачи по следующим направлениям:

- Дискретные сигналы и последовательности.
- Линейные инвариантные системы.
- Импульсные и частотные характеристики.
- Линейная и циклическая свёртка.
- Преобразование Фурье дискретного времени.
- Z-преобразование и обратное Z-преобразование.
- Передаточные функции и структурные схемы.
- Дискретное преобразование Фурье и обратное ДПФ.
- Быстрое преобразование Фурье.
- Случайные сигналы, корреляционные преобразования и фильтр Винера.

## Как пользоваться

### Теория

Выберите раздел и режим изучения. Попробуйте ответить самостоятельно, затем откройте ответ.

Кнопки «Откуда формула» и «Показать пример» помогают разобраться в выводе и применении формул. Отмечайте освоенные вопросы как «Знаю», а сложные — «Повторить».

### Практика

Выберите раздел и тип задачи, затем нажмите «Новая задача».

Введите ответ и проверьте его. При затруднении откройте подсказку или пошаговое решение. Новые варианты позволяют повторять один тип задач с разными данными.

### Справочник

Используйте поиск для быстрого перехода к нужной теме, формуле или типу задачи.

### Билет

Настройте количество теоретических вопросов и практических задач независимо друг от друга. По умолчанию билет содержит **10 вопросов и 5 задач**.

Можно выбрать:

- конкретные разделы теории и практики;
- только теорию или только практику;
- только элементы с отметкой «Повторить»;
- конкретный тип практических задач;
- классические зачётные задачи T1–T5.

В обычном режиме помеченные элементы включаются обязательно. Если выбранного количества мест недостаточно, размер билета увеличивается.

### Прогресс

Раздел показывает статистику подготовки. Прогресс сохраняется автоматически в текущем браузере.

## Хранение данных

Приложение использует `localStorage` для сохранения прогресса и отметок.

- Данные хранятся в браузере на вашем устройстве.
- Они не записываются в GitHub-репозиторий.
- Автоматической синхронизации между устройствами нет.
- Очистка данных сайта или сброс прогресса удаляет сохранённые результаты.
- Локальный HTML и опубликованный сайт используют разные хранилища: прогресс между ними автоматически не переносится.

Экспорт и импорт прогресса в JSON в текущей версии не предусмотрены.

## Локальный запуск

Скачайте `index.html` и откройте его в браузере.

Установка зависимостей, сборка проекта и сервер приложений не требуются.

## Публикация на GitHub Pages

1. Разместите HTML-приложение в корне репозитория под именем `index.html`.
2. Добавьте пустой файл `.nojekyll`.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Укажите ветку **main** и папку **/ (root)**.
6. Сохраните настройки и дождитесь публикации.

Структура репозитория:

```text
index.html
README.md
.nojekyll
```
